# Bon Jesrael Luna Portfolio

Responsive portfolio website based on the supplied resume.

## Project Videos
The Projects & Videos section has a **Choose Video** button for each player.
You can select `8strong.mp4` directly from your computer and it will play immediately
in the browser. This avoids broken paths when opening `index.html` locally.

The selected video is only used by the browser during that session; it is not uploaded.

## Run locally
Open `index.html` in Chrome, Edge, or another modern browser.
